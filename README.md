**Stack:** Node.js · Express.js · Prisma ORM · MySQL · AWS S3

- Layered route → controller → service architecture
- Session-based authentication with role-based access control (Admin, Agent, Customer)

**Goal:** replace a manual IT support workflow with a structured ticketing system.
